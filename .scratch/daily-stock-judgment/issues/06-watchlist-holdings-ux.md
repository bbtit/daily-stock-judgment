# ウォッチリストと保有はどう登録・更新するか

Type: grilling
Status: resolved

## Question

自分専用Web一覧において、ウォッチリストと保有情報をどう追加・変更・削除するか。日次の最低限の操作は何か。数量は必須か。

## Answer

正本は **SQLite**。画面からウォッチリストと保有を追加・変更・削除できる。

- **数量**: 任意（判断ロジックは保有の有無のみ使う。発注・数量提案はスコープ外）
- **日次の最低限操作**: ウォッチリストへの銘柄追加／削除、保有への登録／解除、判断一覧の閲覧
- 一括インポート等は任意の便利機能であり、日次の必須にはしない
