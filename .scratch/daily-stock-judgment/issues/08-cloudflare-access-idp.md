# Cloudflare Accessの認証手段は何か

Type: grilling
Status: resolved

## Question

Tunnel + Cloudflare Access 前提で、自分一人が通る認証手段は何か（ワンタイムPIN付きメール、Googleアカウント等）。仕様にどこまで固定するか。

## Answer

スコープ外。一覧は localhost 前提とし、Cloudflare Tunnel / Access は使わないため、本チケットの前提が消えた。
