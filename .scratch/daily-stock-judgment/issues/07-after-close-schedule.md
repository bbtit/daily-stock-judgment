# 大引け後ジョブの時刻と休場日はどうするか

Type: grilling
Status: resolved

## Question

大引け後に判断一覧を用意するジョブは、いつ走らせるか。日本の休場日・半日取引・データ遅延時にどうするか。ユーザーが手動再実行できるか。

（参考: [yfinance調査](../research/yfinance-japan-daily-ohlcv.md) は東証の約20分遅延を踏まえ、大引け直後より **15:30〜夜** の方が安全とし、当日バー欠落時のリトライを示唆している。）

## Answer

- **起動**: 手動実行が正。自動はローカル OS のスケジューラ（launchd / cron 等）任せで任意。Cloud Agents の定期実行はローカル正本前提と合わないため仕様に含めない
- **推奨時刻**: 営業日 16:00〜21:00 JST（目安 18:00）。大引け直後（15:00台）は避ける
- **休場日**: 新規の判断は作らない（カレンダーまたは当日バーなしで判定）。前営業日を当日扱いにしない
- **半日取引**: 当日バーが取れれば通常の大引け後と同じ
- **遅延・欠落**: 推奨時刻帯で回す。当日バーが無い／欠けるときは捏造せず判断を確定しない。同じ日の手動再実行を常に許す
- リトライ回数・エラー表示・部分成功の細部は [データ欠落とLLM失敗時の扱いは何か](09-data-and-llm-failure-handling.md) で決める
