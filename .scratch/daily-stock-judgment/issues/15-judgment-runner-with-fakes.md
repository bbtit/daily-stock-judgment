# 15 — フェイクで日次判断ランナーが回る

**What to build:** 判断日と登録銘柄から、銘柄ごとにスコア・ラベル・理由、または失敗区分を出せる日次判断ランナー。相場取得と LLM はフェイク差し替え可能。成功した判断だけ保存し、同日再実行は銘柄×判断日で上書きする。

**Blocked by:** 14 — ウォッチ／保有を画面で管理できる

**Status:** ready-for-agent

- [ ] ランナー境界で正常系のスコア・ラベル・理由が得られる（ラベルは固定閾値）
- [ ] 未保有かつスコア ≤ −50 は様子見になる
- [ ] 部分成功・データ未着／取得不可／判断失敗の区分が出る
- [ ] 休場日（または当日バーが市場として無い日）は新規判断を作らない
- [ ] 成功のみ永続化され、同日再実行で上書きされる
- [ ] 相場・LLM フェイクによる seam テストがある（仕様の Testing Decisions に沿う）
