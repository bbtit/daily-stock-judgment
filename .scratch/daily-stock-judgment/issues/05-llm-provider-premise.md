# どのLLMプロバイダとモデルを前提にするか

Type: grilling
Status: resolved

## Question

仕様が前提とするLLMは何か（プロバイダ・モデル世代の粒度）。切り替え可能にするか、コストと日本語・数値遵守のどちらを優先するか。

## Answer

日本語の理由と数値（スコア・価格観察）の遵守をコストより優先する。

実行経路の前提は、特定クラウド API の直呼びではなく **ローカルのエージェント CLI**（Cursor CLI・Claude Code など）。特定プロダクト名やモデルのスナップショット名は仕様に固定しない。デフォルトは高品質帯を想定する。

アプリ内のマルチプロバイダ切替 UI は持たない。どの CLI で回すかは運用側。一覧の閲覧は localhost（Cloudflare Tunnel / Access は使わない）。
