# 短い理由に必須の要素は何か

Type: grilling
Status: resolved

## Question

理由に何を必ず含めるか（具体的な価格水準や変化率への言及、禁止する曖昧表現、長さの上限など）。スコア／ラベルとの矛盾をどう扱うか。

## Answer

理由は「観察必須・解釈は任意」とする。

- **必須の観察**: 終値まわりの水準か変化（前日比・直近高安との位置など）を1つ以上。出来高への言及は任意
- **禁止**: 入力にない情報の断定（ニュース・業績・需給の推測）、数字も水準もない雰囲気だけ（「強気」「堅調」「注目」だけ）、発注を促す言い回し
- **長さ**: おおよそ200文字以内
- **スコア／ラベルとの整合**: 理由本文ではラベル語（買う／売る／様子見）を使わない。解釈の向きはスコアの符号に合わせる旨をプロンプトに書く。符号×極性ワードの事後検証はしない（「直近高値から押し戻し」等が誤検知されるため）
