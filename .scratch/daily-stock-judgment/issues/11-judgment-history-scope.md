# 判断履歴の保存・振り返りを仕様にどこまで書くか

Type: grilling
Status: resolved

## Question

日次の判断（スコア・ラベル・理由）を履歴としてどこまで残すか。保存するなら保持期間・一覧からの振り返り UI の有無を、この仕様の必須範囲に含めるか。

## Answer

- **保存は必須**（SQLite）。成功した判断（スコア・ラベル・理由）のみ残す。失敗区分（データ未着／取得不可／判断失敗）は履歴に残さない
- **振り返り UI**: 過去日の一覧を見られることまでを必須とする。成績グラフ・カレンダー比較などは v1 必須にしない
- **保持期間**: 自動削除なし（無期限）。削除が必要ならユーザー操作
- **同日再実行**: 銘柄×判断日で上書き。版履歴は残さない
