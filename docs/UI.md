# UI

ローカル Web UI（`presentation/templates/index.html`）の見た目の原則。実装の正本はテンプレート内の CSS 変数。ここはその意図を固定する。

## Goals

- 暗い単色の土台の上で、階層と操作だけが読めること
- 色の数を抑え、判断・銘柄・操作以外の装飾を足さないこと

## Palette

許可色は次のみ。これ以外の hex / `rgb` / グラデーションで新しい色味を作らない。

| 用途 | 値 | CSS 変数 |
| --- | --- | --- |
| 背景 | `#141414` | `--bg` |
| 重なり（セクションなど） | `#181818` | `--surface` |
| 文字（白） | `#F0F0F0` | `--ink` |
| アイコン・補助テキスト | `#818181` | `--icon` |
| ボタン縁取り（必要なときのみ） | `#292929` | `--border` |

透明（`transparent`）と、上記色の参照だけの `box-shadow` / `linear-gradient`（セレクト矢印など）は可。明るさフィルタや別色の hover は不可。

## Surfaces

- ページ全体の地: `--bg`
- その上に載るブロック（`section` など）: `--surface`
- セクション内のくぼみ（入力・リスト行・日付チップ）: 再び `--bg`

層は「地 ↔ 重なり」の往復だけ。中間トーンを増やさない。

## Typography & icons

- 本文・見出し・強調: `--ink`
- リード文・プレースホルダ・メタ・空状態・失敗種別など補助: `--icon`
- SVG アイコンの既定色: `--icon`（`currentColor`）

## Buttons

- **主操作**（実行・追加・表示・登録など）: `1px solid --border`。背景は透明、アイコンは `--icon`
- **消去系**（ウォッチリスト削除・保有解除など `.secondary`）: 縁取りなし。背景も透明のまま

hover で色味を増やさない。必要なら `--ink` への切り替えと `--bg` 背景程度に留める。

## Out of scope for this document

レイアウト幅・余白・角丸の数値、アニメーション、アクセシビリティの詳細セマンティクスはテンプレート側の実装詳細。色と縁取りのルールだけをここで拘束する。
